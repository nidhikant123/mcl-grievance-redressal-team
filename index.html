About the system

MCL-LRMS brings acquisition records, maps, GIS locations, field verification and grievances into one place, so that acquired plots can be identified faster and every grievance is traceable.

The system is an AI-assisted decision-support tool. It does not declare ownership, decide title, determine lawful possession, approve compensation or R&R, or alter official land records. Final decisions remain with the competent MCL authorities.

Land-related services

  • Register a grievance on acquisition, compensation, R&R, employment/annuity, demarcation, possession or records
  • Track your grievance with the reference number
  • File a representation after disposal (where permitted)
  • See the verification status of a plot on the map
